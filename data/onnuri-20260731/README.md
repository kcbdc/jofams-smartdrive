- 원본 기준: `온누리상품권_전국가맹점_주소보강_8차_20260731.csv`
- 원본 전체 가맹점: 225,803건
- 앱 정적 주소 데이터: 최종 활용주소가 확인된 행을 동일 행 중복 제거 후 83,843건

- 주소가 확인되지 않은 행은 기존 공공데이터 API/키워드 검색 fallback 흐름을 유지
