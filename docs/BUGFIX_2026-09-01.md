# 버그 수정 내역 (2026-09-01)

첨부한 UI 제안 이미지와 실제 배포본을 비교해 아래 문제를 확인하고 수정했습니다.

## 1. 모바일 레이아웃 붕괴 (핵심 버그)
`styles.css`의 `@media (max-width:520px)` 구간 — 즉 **실제 폰 화면 전부** —
에서 아래 4개 그리드의 열 개수를 임의로 줄이는 규칙이 있었습니다. 데스크톱
CSS에는 올바른 값(3열/4열)이 있었지만, 모바일에서는 항상 이 규칙에 덮여
써서 실제 폰에서는 한 번도 의도한 모습으로 보이지 않았습니다.

| 영역 | 의도한 모습 (이미지 기준) | 실제 폰에서 보이던 모습 |
|---|---|---|
| 집 / 회사 / 즐겨찾기 | 한 줄 3개 | 2열 + 즐겨찾기 전체폭 |
| 주변 탐색 (주유소·카페·편의점·충전) | 한 줄 4개 | 2×2 |
| 조팸스 가이드 캐릭터 선택 | 한 줄 3개 | 세로 1열(카드가 큼) |
| MY 페이지 퀵그리드 / 가이드 모드 | 한 줄 4개 | 2×2 |

→ 해당 모바일 오버라이드 규칙 4개를 제거하고, 좁은 화면에서도 텍스트가
잘리지 않도록 즐겨찾기 카드의 패딩·폰트·말줄임 처리를 다듬었습니다.

## 2. CSS 변수 오타
`var(--safe-top)`, `var(--safe-bottom)` 처럼 하이픈이 들어간 잘못된 변수명이
세 곳에서 쓰이고 있었습니다. 실제 정의된 변수는 `--safeTop` / `--safeBottom`
(카멜케이스)이라 해당 규칙은 조용히 무시되고 있었습니다. 정확한 변수명으로
수정했습니다.

## 3. 미사용 코드 정리
README 변경 이력에 "MY 화면의 서비스 연동 상태 점검 UI 제거"라고 되어 있었지만,
HTML에서는 이미 제거된 후에도 관련 CSS(`.integration-check-card`,
`.integration-status-list`, `.status-dot` 등, 약 15줄)가 남아 있었습니다. 이제
정리했습니다.
