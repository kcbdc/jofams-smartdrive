# MVP6 주행 구조

1. `/api/search`로 목적지 검색
2. `/api/route`에 추천/시간/무료도로 3개 요청
3. 경로 카드 표시
4. 3초 자동 안내 또는 `안내 시작`
5. `watchPosition()`으로 GPS 지속 수신
6. 지도상의 선택 캐릭터 자동차 마커를 GPS 좌표로 이동
7. 현재 위치를 route geometry에 매칭하여 남은 거리/시간과 guides 계산
8. 경로 이탈 70m 초과 시 자동 재탐색
9. 목적지 28m 이내에서 도착 안내 후 종료

웹 앱이 시스템 미디어 볼륨을 직접 제어할 수 없기 때문에 주행 메뉴에는 앱의 길안내 TTS 볼륨만 제공합니다.
