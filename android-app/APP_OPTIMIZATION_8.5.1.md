# Jofams Navi 8.5.1

- `native_loading_screen`을 FIT_CENTER 기반 반응형 부트스트랩으로 변경: 화면 회전/해상도 변화에도 원본 비율 유지 자동 확대·축소
- 네이티브 음성 길안내를 속도·거리 기반 3단계(far/near/now)로 개선하고 복잡한 분기/램프 사전안내 거리를 확대
- 구간단속 종료 130m 전 별도 종료 음성안내 추가
- 목적지 정문/진입구간 도착판정 추가: 일반 목적지 75m, 대형 시설 120m, 한국조폐공사 본사 190m 경로 잔여거리 기준 + 직선거리 교차검증 후 자동 종료
- 단속카메라 경로 매칭 개선: 일반 72m/구간단속 95m, 방향각 제공 데이터는 역방향 카메라 제거
- 홈화면 지역사랑상품권/온누리상품권 레이어를 페이지 로드 직후 및 위치 갱신 시 선행 로딩하도록 WebView bootstrap prefetch 추가
- 앱 버전 8.5.1 / versionCode 110

## 빌드 점검
- 소스 구조/괄호 정합성 점검 완료.
- 이 실행환경에는 Gradle 8.11.1 배포본 캐시가 없고 외부 다운로드가 차단되어 실제 Gradle compile은 수행하지 못함.
- 기존 8.5.0 `app-release.aab`는 새 소스와 버전이 달라 혼동 방지를 위해 수정본 ZIP에서 제외함.
