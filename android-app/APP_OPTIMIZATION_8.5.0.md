# 조팸스 내비 Android 8.5.0 GPS/최적화 개선

## GPS/안내 정확도
- FusedLocation + GPS_PROVIDER 병행 수신 유지
- 활성 위치 요청 주기 200ms, 최소 100ms로 상향하고 오래된 fix 허용시간을 1초로 제한
- 앱/엔진 시작 시 고정밀 단일 fix를 즉시 한 번 더 요청하여 초기 위치 확보시간 단축
- Fused/GPS가 같은 시각대에 중복 도착할 때 품질점수가 낮은 위치 후보 제거
- 비현실적인 순간 위치 점프를 속도/경과시간/정확도로 필터링
- 정차 중 GPS 드리프트를 고정 앵커로 억제
- 주행 중 raw GPS는 보존하되 표시 위치는 진행방향·정확도·경로거리 조건을 통과한 경우에만 경로에 가중 스냅
- 경로이탈은 GPS 오차에 따라 임계값을 자동 조절하고 연속 3회 확인 후 재탐색하여 평행도로/교량/램프 오탐 감소
- GPS 단절 시 기존 90초 경로 기반 dead-reckoning과 센서 heading 보완 유지
- 위성수·CN0·경로 일치도를 반영한 confidence 계산 개선

## 앱 최적화
- WebView 하드웨어 가속 레이어 고정
- offscreen pre-raster 활성화 및 기본 HTTP 캐시 사용
- 지도 확대 기능 중 WebView 자체 확대는 비활성화하여 터치 충돌 감소
- Manifest 하드웨어 가속 명시
- 버전: versionCode 109 / versionName 8.5.0

## 정확도 목표에 대한 참고
GPS RF 수신감도 자체는 앱 소프트웨어로 증폭할 수 없으며 단말, 위성 가시성, 터널/고층건물, 제조사 GNSS 칩셋의 영향을 받습니다. 따라서 '100% 정확도'를 보장할 수는 없지만, 앱이 받을 수 있는 고정밀 GNSS·Fused·센서 정보를 더 빠르고 안정적으로 선택하고 경로 안내에 반영하도록 개선했습니다.
