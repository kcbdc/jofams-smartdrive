# 조팸스 스마트 드라이브 · MVP5 Pre

상용화 가능한 화면 디자인 제안 시안을 반영한 **MVP5 프리버전**입니다.

## 이번 버전 핵심 반영
- 메인 진입 화면 상단 **햄버거 버튼 / 알림 벨 버튼** 적용
- 홈 / 목적지 검색 / 최근 목적지 / 주변 탐색 UI 정돈
- 다임 · 순식 · 훈민 캐릭터 카드형 가이드 영역 강화
- 경로 옵션 선택 화면의 카드형 구조 및 캐릭터 연계 UI 개선
- 주행 HUD 상단 안내 카드 및 차선 안내 시인성 개선
- AR 내비게이션 상단 방향 카드 / 파란 경로 리본 / 말풍선 위치 개선
- 주차장 추천 카드의 상태 배지 / 안내 버튼 강화
- 마이페이지를 상용 앱 느낌의 카드형 설정 화면으로 개선
- 좌측 메뉴 서랍 및 우측 알림 모달 추가
- Firebase 로그인 / 즐겨찾기 / 주행기록 / 사용자 장소 등록 기능 유지
- 한국조폐공사 본사 검색 우선 노출 로직 유지
- 서비스워커 캐시 갱신

## 배포 방법
기존과 동일하게 Cloudflare Pages / Functions 배포가 가능합니다.

1. 프로젝트 업로드
2. `config.js` 에 Kakao / Firebase 값 입력
3. Cloudflare Pages 프로젝트 생성
4. `functions/` 포함하여 배포
5. D1 사용 시 `wrangler.toml` 의 데이터베이스 ID 실값으로 변경

## 참고
- 기존 환경설정 파일을 유지하면서 UI 중심 고도화가 가능하도록 구성했습니다.
- 브라우저 캐시가 남아 있으면 새 UI가 늦게 반영될 수 있으므로 강력 새로고침 또는 서비스워커 갱신 후 확인하세요.
