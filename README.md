# 조팸스 내비 MVP 7.5

## 주요 개선

### 지도 로딩 안정화
- MapLibre GL JS 6.6.0을 v6 권장 방식인 ESM(`maplibre-gl.mjs`)으로 동적 로딩
- unpkg 실패 시 jsDelivr ESM으로 자동 fallback
- 기본 지도 타일을 브라우저가 외부 서버에 직접 요청하지 않고 Cloudflare Pages Function `/api/tile`을 통해 same-origin으로 제공
- `/api/tile`은 CARTO 타일을 우선 사용하고 실패 시 OpenStreetMap 타일로 fallback
- Cloudflare edge cache 및 브라우저 cache-control 적용
- Pages Function 타일 프록시 실패 시 브라우저에서 OSM → CARTO 직접 타일 fallback 유지
- 지도 진입 시 resize 및 경로 재렌더링 유지

### 캐릭터 음성
- 순식: 저음 중년 남성 보이스 우선 선택
  - rate 0.86
  - pitch 0.62
  - 성숙/저음/남성 계열 TTS 이름 우선
- 훈민: 밝은 청년 남성 보이스 우선 선택
  - rate 1.12
  - pitch 1.08
  - 젊은/밝은/남성 계열 TTS 이름 우선
- 기기에 한국어 남성 TTS가 여러 개 있으면 순식과 훈민이 서로 다른 음성을 우선 사용
- 전용 음성이 없는 기기에서는 rate/pitch 차이로 캐릭터 성격을 유지

## Cloudflare 배포
`functions/api/tile.js`가 반드시 함께 배포되어야 합니다.

배포 후 다음 주소가 이미지 타일을 반환하는지 확인할 수 있습니다.

`/api/tile?z=14&x=13985&y=6469`

Pages Functions가 정상 배포되어 있다면 HTTP 200 및 PNG 이미지가 반환됩니다.

## MVP 7.0 교통정보·도로상황·주변검색 개선
- 주행 HUD에 `원활 / 서행 / 지체·혼잡 / 정체·극심한 정체` 4단계 교통상태를 표시합니다.
- 도시 일반도로 예시 기준은 40km/h 이상 원활, 20~40km/h 서행, 20km/h 미만 정체로 적용하며, 공급자의 혼잡 상태값이 있으면 `지체·혼잡`을 별도로 세분화합니다.
- Kakao 경로 road segment의 `traffic_speed / traffic_state`가 제공되면 경로선에도 초록/노랑/주황/빨강으로 교통상태를 표시합니다.
- 이동식 단속카메라, 도로공사, 교통사고 이벤트를 경로상 안전 이벤트로 통합하여 지도 마커·상단 경고·음성으로 안내합니다. Kakao affiliate road-event 정보가 있으면 우선 사용하고, OSM/Overpass는 보조 데이터로 사용합니다. 실시간 사고/이동식단속 정확도가 필요한 상용 서비스는 공식 교통정보 공급원 연동이 필요합니다.
- `주유소 / 마트 / 편의점 / 주차장 / 충전소` 등 생활편의시설 검색은 GPS가 있으면 현재 위치 거리순으로 정렬합니다. 역명·상호명처럼 고유 장소를 검색하는 경우에는 기존 정확도 우선 정렬을 유지합니다.

## MVP 7.2.2 TTS 변경
- 순식·훈민의 Supertonic/Hugging Face TTS 경로를 제거했습니다.
- Web Speech API `speechSynthesis.getVoices()`에서 한국어 남성 후보를 우선 선택합니다.
- 순식은 저음·중년 남성 느낌(rate 0.82 / pitch 0.58), 훈민은 밝은 남성 느낌(rate 1.08 / pitch 0.92)으로 보정합니다.
- 기기에 남성으로 식별 가능한 한국어 음성이 없으면 여성 힌트 음성을 피한 한국어 음성, 그마저 없으면 첫 한국어 음성으로 fallback 합니다.
- 실제 사용 가능한 음성 목록은 Android/브라우저/OS에 설치된 TTS 엔진에 따라 달라집니다.


## MVP 7.3 AR 유도선 개선
- AR 카메라 위의 기존 반투명 도로 리본/외곽 테두리를 완전히 제거했습니다.
- 유도 정보는 각진 형태의 파란 방향 화살표만 표시합니다.
- 가까운 화살표는 넓고 두껍게, 원거리 화살표는 작고 선명하게 표현하여 원근감을 강화했습니다.
- 16단계 원거리 화살표 배열로 기존보다 더 멀리 뻗어 보이도록 했습니다.
- 화살표는 시안/블루 다중 투명 그라데이션과 soft glow를 사용해 반짝이는 느낌을 강화했습니다.
- 상단 원거리 화살표 간격은 비선형 배치로 유지해 서로 겹치지 않습니다.
- 카메라 도로 화면을 가리지 않도록 화살표 본체도 반투명으로 유지합니다.

## MVP 7.4 안전·터널·교통정보 안정화

- 경찰청/지자체가 제공하는 `전국무인교통단속카메라표준데이터` OpenAPI를 `/api/safety`에서 우선 조회합니다.
  - Cloudflare Pages 환경변수 `DATA_GO_KR_SERVICE_KEY`가 필요합니다.
  - 카카오 좌표→행정구역 변환 후 현재 경로가 지나는 시도/시군구의 카메라를 조회하고 경로 주변만 필터링합니다.
  - 속도/신호 단속 카메라의 제한속도가 제공되면 주행 HUD의 제한속도와 과속 경고에 사용합니다.
- Kakao Mobility `traffic_state` 공식 코드(1 정체, 2 지체, 3 서행, 4 원활, 6 사고/통행불가)에 맞춰 교통정보 색상을 수정했습니다.
- GPS가 2.5초 이상 끊기고 마지막 차량속도가 유효하면 최대 120초 동안 경로 누적거리 위에서 1초 단위 dead-reckoning으로 위치를 추정합니다. GPS가 돌아오면 즉시 실제 좌표로 복귀합니다.
- 일반 지도 캐릭터 마커는 `*_car_rear.png` 후면 자산을 사용합니다.
- AR은 화살표를 제거하고, 낮은 소실점(화면 약 43%)을 가진 반투명 파란색 주행 구역으로 변경했습니다.
- 실시간 경로는 120초 주기로 조회하며, 기존 예상시간보다 120초 이상 단축될 때만 경로를 자동 교체하고 음성 안내합니다. 교체하지 않을 때도 최신 교통상태를 기존 경로에 매칭해 오른쪽 교통 막대에 반영합니다.
- 과속 경고는 `현재속도 >= 제한속도 + 3km/h`에서 작동하고 9초 음성 쿨다운, 클릭 통과형 오버레이, 모션 감소 설정을 유지합니다.

### AR 중앙 정렬 보정
- AR 주행 리본이 회전 안내에 따라 우측/좌측 대각선으로 기울던 보정값을 제거했습니다.

- 유도 리본의 최대 전체 폭을 화면 폭의 1/3 이내로 제한해 시야를 과도하게 가리지 않도록 조정했습니다.

## MVP 7.5 장소 검색 정확도·거리 표시 개선
- 검색 결과의 거리값이 `null`일 때 `0m`로 표시되던 오류를 수정했습니다.
- 일반 지명 검색도 위치 권한이 허용되어 있으면 GPS 좌표를 검색 API에 전달하고, 모든 결과에 현재 위치 기준 직선거리를 계산합니다.
- 공공기관·기업·관광지·리조트·놀이동산 등 고유 지명은 `정확 일치 > 행정구역 명칭을 완화한 일치 > 이름 포함 > 주소 포함` 순으로 강하게 우선 정렬합니다.
- `대전시청`처럼 실제 등록명이 `대전광역시청`인 경우도 행정구역 수식어를 완화해 본체 지명을 우선 배치합니다.
- 편의점·주유소·주차장·마트·경찰서·파출소·지구대·소방서·119안전센터·공중/공용화장실·공공기관 등의 그룹 검색은 현재 GPS 기준 거리순으로 정렬합니다.
- Kakao Local의 카테고리 코드가 있는 그룹은 카테고리 검색과 키워드 검색을 병합해 누락을 줄입니다.

## 다른시간 출발 AI 소요시간 예측
- 마이페이지에 `다른시간 출발` 메뉴를 추가했습니다.
- 출발지 / 도착지 검색 후 오늘, 내일, 날짜 선택 방식으로 출발일을 지정할 수 있습니다.
- 오전 / 오후를 선택하고 시간은 1~12시, 분은 00/10/20/30/40/50의 10분 단위로 선택합니다.
- 현재 경로 소요시간을 계산한 뒤 평일 출퇴근, 점심시간, 주말, 심야 시간대 가중치를 반영하여 예측 소요시간과 예상 도착시각을 표시합니다.
- 현재 구현은 과거 교통 빅데이터 기반 상용 예측 API가 아니라 시간대 휴리스틱을 사용하는 MVP 예측이므로 화면에 예측치 안내를 표시합니다.


## MVP 7.5.1 주행 안정화
- 자동 재탐색은 정기 주기가 아니라 경로 이탈이 연속 3회 확인될 때만 실행합니다.
- 하단 재탐색 아이콘은 현재 위치로 지도 중심을 맞추는 기능으로 변경했습니다.
- 제한속도는 현재 도로 세그먼트 제공값을 우선하고, 로컬 카메라/OSM 값은 동일 도로명 또는 동일 세그먼트일 때만 보조 적용합니다.
- 과속 전체화면 경고는 전방 600m 이내 속도단속 카메라가 있고 현재속도가 제한속도보다 3km/h 이상 높을 때만 표시합니다.
- 안전/과속/VMS 팝업을 중앙 안전영역으로 축소·재배치했습니다.
- 집/회사 저장의 누락된 localStorage 키 상수를 복구하고 현재 위치 등록 및 로그인 사용자 Firestore 저장을 보강했습니다.
- AR 리본은 화면 전체 높이의 약 23.5% 이내에만 표시됩니다.


## MVP 7.5.2 장소관리·AR·도착공유 UX 보정
- 집/회사 위치에 별도 관리 버튼을 추가했습니다.
- 검색 결과를 선택하면 즉시 저장하지 않고 선택 장소 카드가 나타나며, 등록/변경 버튼으로 확정합니다.
- 이미 저장된 집/회사는 삭제 버튼으로 즉시 삭제할 수 있습니다.
- 저장/변경/삭제 후 화면 피드백과 토스트를 동시에 표시합니다.
- 로그인 사용자는 기존 Firestore preferences 동기화를 유지하고, 비로그인 사용자는 로컬 설정으로 저장합니다.
- AR 유도 리본 표시 높이를 화면 세로 높이의 약 30% 이내로 확대했습니다.
- 도착 공유 문구를 `'장소명' 이동 중입니다. 예상 도착 00:00` 형식으로 변경했습니다.


## MVP 7.5.2 집·회사 D1 저장 안정화
- Cloudflare D1 `saved_places` 테이블을 추가했습니다. (`migrations/0003_saved_places.sql`)
- `/api/places`가 집/회사 위치의 조회, 등록/변경, 삭제를 처리합니다.
- 함수가 최초 실행될 때 테이블이 없으면 `CREATE TABLE IF NOT EXISTS`로 자동 보완합니다.
- 로그인 사용자는 Firebase UID 기반 owner key, 비로그인 사용자는 기기별 installation ID 기반 owner key를 사용합니다.
- 로컬스토리지와 D1을 함께 사용해 네트워크 장애 시에도 기기 저장은 유지합니다.
- 등록/변경/삭제 완료 시 화면 중앙 확인 팝업이 표시됩니다.

### D1 적용 확인

npx wrangler d1 migrations apply jofams-smartdrive-db --remote

## MVP 7.5.3 개인별 주행 설정 / 1:1 문의
- 경로 우선순위 `추천 / 빠른길 / 무료도로`를 D1 `user_navigation_settings`에 사용자별 저장합니다.
- 선택값은 새 경로 조회의 기본 선택 및 경로 이탈 재탐색에 반영됩니다.
- 과속/신호위반 카메라 알림을 각각 ON/OFF하고 D1에 저장합니다. OFF된 종류는 화면 및 음성 경고에서 제외됩니다.
- `고객센터 / 이용약관`을 `1:1 문의`로 변경했습니다.
- 문의는 Firebase 로그인 필수이며 Cloudflare Function이 Firebase ID 토큰을 `accounts:lookup`으로 확인한 뒤 토큰의 UID를 DB 쿼리에 강제 사용합니다. 따라서 클라이언트가 다른 UID를 임의로 지정해도 다른 사용자의 문의를 조회할 수 없습니다.
- 신규 migration: `0006_user_navigation_settings.sql`
- 신규 Functions: `/api/user-settings`, `/api/inquiries`
- Cloudflare 환경변수 `FIREBASE_WEB_API_KEY`를 Firebase Web App의 API key로 설정해야 1:1 문의 인증이 동작합니다.
